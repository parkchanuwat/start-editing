ซับไตเติลภาษาเกาหลีและจีนตัวย่อ

Premiere ถอดเสียงเป็นข้อความด้วย Speech to Text แล้วสร้างเป็น captions บน timeline ได้ ใช้กับภาษาเกาหลีและจีนตัวย่อได้ทั้งคู่ แต่ภาษากลุ่ม CJK ต้องตั้งความยาวบรรทัดคนละแบบกับภาษาอังกฤษ และต้องใช้ฟอนต์ที่มีตัวอักษรของภาษานั้น

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe และ Netflix

ติดตั้ง language pack ก่อน Premiere มี language pack ภาษาอังกฤษมาให้ ส่วนภาษาเกาหลี (Korean) และจีนกลางตัวย่อ (Simplified Chinese, Mandarin) ต้องดาวน์โหลดแยก ติดตั้งแล้วถอดเสียงได้โดยไม่ต้องต่ออินเทอร์เน็ต

ขั้นตอน

  1. เปิด Text panel และถอดเสียง

    ไปที่ Window › Text แท็บ Transcript เลือกภาษาให้ตรงกับเสียงพูด (Korean หรือ Simplified Chinese) แล้วกด Transcribe

  2. ตรวจ transcript ก่อน

    อ่านทวนและแก้คำผิด ชื่อคน ชื่อสินค้า ศัพท์เฉพาะ ในแท็บ Transcript ให้เรียบร้อย แก้ตรงนี้ครั้งเดียวดีกว่าไปแก้ทีละซับ

  3. สร้าง captions และตั้งความยาวบรรทัด

    เปิดเมนู (ไอคอนสามขีด) ในแท็บ Transcript เลือก Create Captions ช่อง Maximum length in characters มีค่าเริ่มต้น 42 ซึ่งเหมาะกับภาษาอังกฤษ สำหรับเกาหลีและจีนตัวย่อให้ลดลงประมาณ 16 (ดูตารางด้านล่าง) แล้วเลือกบรรทัดเดียวหรือสองบรรทัด

    ค่าอื่นในหน้าต่างนี้ เช่น Minimum duration in seconds (ค่าเริ่มต้น 3) และ Gap between captions ปรับตามงาน

  4. เลือกฟอนต์ที่รองรับภาษา

    เลือก caption track แล้วตั้งฟอนต์ใน Properties panel ให้เป็นฟอนต์ที่มีตัวอักษรเกาหลีหรือจีน เช่น ตระกูล Source Han Sans ถ้าฟอนต์ไม่มีตัวอักษร จะขึ้นเป็นกล่องสี่เหลี่ยมแทน

  5. แปลซับ (ถ้าต้องการ)

    ในแท็บ Captions ของ Text panel กดปุ่ม Translate Captions ด้านบน เลือกภาษาปลายทางแล้วกด Translate ซับที่แปลแล้วต้องให้คนที่อ่านภาษานั้นได้ตรวจอีกรอบ

  6. Export ซับ

    ในหน้า Export ส่วน Captions เลือกว่าจะฝังซับลงภาพ (Burn Captions Into Video) หรือส่งเป็นไฟล์แยก (Create Sidecar File) เช่น SRT สำหรับอัปโหลดขึ้นแพลตฟอร์มให้คนดูเปิดปิดเองได้

ความยาวบรรทัดและความเร็วในการอ่าน

ค่าด้านล่างมาจาก Timed Text Style Guide ของ Netflix ซึ่งเป็นมาตรฐานที่คนทำซับใช้อ้างอิงกันมาก แม้งานจะไม่ได้ส่ง Netflix ก็ใช้เป็นจุดเริ่มได้

ภาษาตัวอักษรต่อบรรทัดความเร็วอ่านสูงสุด (ผู้ใหญ่)หมายเหตุ
เกาหลี1612 ตัว/วินาทีอักษรละติน เว้นวรรค และเครื่องหมายวรรคตอนนับเป็น 0.5 ตัว
จีนตัวย่อ169 ตัว/วินาทีปกติให้อยู่บรรทัดเดียว ถ้าต้องขึ้นสองบรรทัด ให้บรรทัดล่างยาวกว่าบรรทัดบน
อังกฤษ (เทียบ)42–ใช้กับภาษาที่เขียนด้วยอักษรละตินส่วนใหญ่

ระบบตรวจอัตโนมัติของ Netflix บังคับเพดานไว้ที่ 23 ตัวต่อบรรทัดสำหรับเกาหลีและจีน ถ้าเกินนี้ไฟล์จะไม่ผ่าน ส่วน 16 คือค่าที่ควรใช้ตามคู่มือ

มีไฟล์ซับจากที่อื่นอยู่แล้ว

ถ้าได้ไฟล์ SRT จากนักแปลหรือบริการถอดเสียงอื่น import เข้า Project panel ได้เลย แล้วลากลง sequence เป็น caption track จากนั้นตั้งฟอนต์และตรวจเวลาเหมือนซับที่สร้างใน Premiere

จุดที่มือใหม่พลาดบ่อย

  • ตัวอักษรเป็นกล่องสี่เหลี่ยมฟอนต์ไม่มีตัวอักษรเกาหลีหรือจีน เปลี่ยนเป็นฟอนต์ที่รองรับ CJK
  • ใช้ค่า 42 ตัวกับภาษาเกาหลีหรือจีนบรรทัดยาวจนล้นจอหรืออ่านไม่ทัน ลดลงประมาณ 16 ตอน Create Captions
  • เลือกภาษาผิดตอนถอดเสียงผลออกมาเป็นคำมั่ว ๆ เช็กภาษาใน Transcript ก่อนกด Transcribe และติดตั้ง language pack ให้ครบ
  • ผลการแบ่งบรรทัดไม่ตรงกับค่าที่ตั้งPremiere แบ่งซับตามจังหวะการพูดด้วย บางซับอาจยาวหรือสั้นกว่าที่ตั้ง ต้องไล่ตรวจเองเสมอ
  • ฝังซับลงภาพแล้วต้องแก้คำผิดต้อง export ใหม่ทั้งไฟล์ ถ้าแพลตฟอร์มรองรับ ส่งเป็นไฟล์ SRT แยกจะแก้ง่ายกว่า

ถ้าใช้เวอร์ชันเก่า

เรื่องภาษาที่รองรับ
  • รายการภาษาของ Speech to Text และ Translate Captions เปลี่ยนตามเวอร์ชัน เช็กหน้า Languages supported by Speech-to-Text ของ Adobe ก่อนเริ่มงาน
  • ตั้งแต่ Premiere 22.2 ถอดเสียงแบบออฟไลน์ได้เมื่อติดตั้ง language pack แล้ว
