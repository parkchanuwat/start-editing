After Effects

ทำตัวหนังสือเคลื่อนไหว

ตัวหนังสือใน After Effects ขยับได้ทั้ง layer หรือขยับทีละตัวอักษร ทีละคำ ทีละบรรทัด ด้วย text animator วิธีที่เร็วที่สุดคือเริ่มจาก animation preset แล้วค่อยแกะดูว่าข้างในตั้งค่าไว้อย่างไร

  • After Effects 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

แกะสูตรจาก preset: ใส่ animation preset ให้ text layer แล้วกด U หรือ UU จะเห็นเฉพาะค่าที่ preset นั้นขยับหรือแก้ไว้

สร้าง text layer

  1. เลือก Type tool

    กด Ctrl+T / Cmd+T คลิกหนึ่งครั้งใน Composition panel เพื่อพิมพ์แบบบรรทัดเดียว (point text) หรือลากเป็นกรอบเพื่อพิมพ์แบบย่อหน้า (paragraph text)

  2. ตั้งฟอนต์และขนาด

    ใช้ Character panel หรือ Properties panel ถ้าพิมพ์ภาษาเกาหลีหรือจีน ต้องเลือกฟอนต์ที่มีตัวอักษรนั้น ไม่อย่างนั้นจะเห็นเป็นสี่เหลี่ยม

วิธีที่ 1: ใช้ animation preset

  1. เปิด Effects & Presets panel

    ไปที่ Animation Presets › Text จะเห็นหมวดเช่น Animate In, Animate Out, Blurs

  2. ลาก preset ไปวางบน text layer

    preset จะเริ่มที่ตำแหน่ง playhead กด Spacebar เพื่อดูผล

    ถ้าอยากเห็นตัวอย่างก่อนใช้ เลือก Browse Presets จากเมนูของ Effects & Presets panel เพื่อเปิดใน Adobe Bridge

วิธีที่ 2: ทำเองด้วย text animator

  1. เพิ่ม animator

    เปิด text layer ใน Timeline คลิก Animate แล้วเลือกค่าที่จะขยับ เช่น Opacity หรือ Position หรือใช้เมนู Animation › Animate Text

  2. ตั้งค่า "ปลายทาง" ของตัวอักษร

    เช่นตั้ง Opacity เป็น 0% ตัวอักษรที่อยู่ในช่วงของ Range Selector จะได้ค่านี้

  3. animate ช่วงของ Range Selector

    เปิด Range Selector 1 กด stopwatch ของ Start ที่ 0% แล้วเลื่อนเวลาไปข้างหน้าและตั้ง Start เป็น 100% ตัวอักษรจะค่อย ๆ ปรากฏทีละตัว

  4. เลือกหน่วยใน Advanced

    ใน Range Selector › Advanced › Based On เลือกได้ว่าจะนับเป็นตัวอักษร คำ หรือบรรทัด

ไอเดียที่ทำได้ด้วย animator

  • พิมพ์ดีด Opacity 0% แล้ว animate Start จาก 0 ถึง 100%
  • ลอยขึ้นทีละตัว Position Y +30 และ Opacity 0% ด้วย Range Selector เดียวกัน
  • ตัวสั่น เพิ่ม Wiggly Selector แทน Range Selector
  • น้ำหนักฟอนต์เปลี่ยน ใช้ variable font แล้วเพิ่ม animator ของแกน Weight

ข้อผิดพลาดที่มือใหม่เจอบ่อย

  • animate ทั้ง layer แทนที่จะเป็นทีละตัวค่า Transform ของ layer ขยับทั้งก้อน ถ้าอยากให้ทีละตัวต้องใช้ animator
  • Start กับ End สับสนตัวอักษรที่อยู่ระหว่าง Start และ End คือตัวที่ได้ค่าของ animator ลองดูแถบช่วงใน Composition panel ประกอบ
  • ตัวอักษรเกาหลีหรือจีนเป็นสี่เหลี่ยมฟอนต์ไม่มีตัวอักษรนั้น เปลี่ยนเป็นฟอนต์ที่รองรับภาษานั้น
  • ภาพตัวหนังสือดูกระตุกเปิด motion blur ให้ text layer จะดูนุ่มขึ้น

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

After Effects 25.x–26.x
  • text animator และ Range Selector ใช้แบบเดียวกัน
  • การ animate แกนของ variable font มีตั้งแต่ 26.0
  • ข้อความจาก Illustrator ที่แก้ต่อได้ใน After Effects เพิ่มเข้ามาใน 27.0
