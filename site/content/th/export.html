Export วิดีโอ

Export คือการเปลี่ยน sequence ให้เป็นไฟล์วิดีโอที่เปิดดูได้ทุกที่ ใน Premiere ให้เริ่มจากถามตัวเองว่าจะเอาไฟล์ไปไว้ที่ไหน แล้วเลือก preset ที่เหมาะกับปลายทางนั้น

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ดู Range ทุกครั้ง ถ้ามีจุด In/Out ค้างอยู่ใน sequence Premiere อาจ export แค่ช่วงนั้น ตั้ง Range เป็น Entire Source ถ้าต้องการทั้งเรื่อง

สามทางในการ export

วิธีเหมาะกับอยู่ตรงไหน
Export modeงานทั่วไป ตั้งค่าได้ครบแท็บ Export บน header bar หรือ Ctrl+M / Cmd+M
Quick Exportส่งไฟล์ด่วนด้วย preset สำเร็จรูปปุ่มมุมขวาบนของ header bar
Send to Media Encoderหลายไฟล์ หลายสเปก หรืออยากตัดต่อต่อระหว่าง exportปุ่มล่างขวาของ Export mode

ขั้นตอนใน Export mode

  1. เลือก sequence แล้วเข้า Export mode

    คลิกที่ timeline หรือ sequence ใน Project panel ก่อน แล้วกดแท็บ Export

  2. เลือกปลายทาง

    ด้านซ้ายมี Media File สำหรับไฟล์ทั่วไป และปลายทางโซเชียลบางแห่งที่อัปโหลดให้ได้เลย

  3. ตั้งชื่อไฟล์ ที่เก็บ และ preset

    ตั้ง File Name และ Location ให้หาเจอง่าย แล้วเลือก Preset เช่น Match Source – Adaptive High Bitrate ซึ่งใช้ codec H.264 ขนาดและ frame rate ตาม sequence

  4. เช็ก Range และ Captions

    Range ใต้ภาพตัวอย่างมี Entire Source, Source In/Out, Work Area และ Custom ถ้ามีซับ ให้เลือกในส่วน Captions ว่าจะไม่ใส่ ส่งเป็นไฟล์แยก (sidecar) หรือฝังลงในภาพ

  5. ดูขนาดไฟล์โดยประมาณแล้วกด Export

    ด้านล่างขวาบอก Estimated File Size ถ้าใหญ่เกินที่ส่งได้ ลอง preset Medium Bitrate กด Export แล้วรอจนเสร็จ

  6. เปิดดูไฟล์ที่ได้

    เปิดไฟล์จริงดูตั้งแต่ต้นจนจบ เช็กภาพ เสียง ซับ และช่วงท้ายว่าไม่มีภาพดำเกิน

ค่าที่ควรรู้จัก

ค่าความหมาย
Formatชนิดไฟล์และ codec เช่น H.264 (MP4), HEVC, QuickTime (ProRes)
Match Sourceใช้ขนาดภาพและ frame rate ตามต้นฉบับอัตโนมัติ
Bitrateปริมาณข้อมูลต่อวินาที ยิ่งสูงยิ่งคมแต่ไฟล์ใหญ่ VBR ปรับตามความซับซ้อนของภาพ ส่วน CBR คงที่ตลอด
Use Maximum Render Qualityช่วยคุณภาพตอนย่อขนาดภาพ แต่ใช้เวลานานขึ้น
Content Credentialsแนบข้อมูลว่าใครสร้างและแก้ไขไฟล์ไว้ในไฟล์ (เลือกเปิดได้)

ขนาดภาพและ preset สำหรับปลายทางต่าง ๆ ดูเพิ่มที่หน้า Preset และ Resolution ที่ใช้บ่อย

ข้อผิดพลาดที่มือใหม่เจอบ่อย

  • ได้วิดีโอแค่บางช่วงRange ถูกตั้งเป็น Source In/Out จากจุด In/Out ที่ค้างไว้ เปลี่ยนเป็น Entire Source
  • หาไฟล์ไม่เจอดู Location ก่อนกด Export และตั้งชื่อไฟล์ให้มีวันที่หรือเวอร์ชัน
  • ซับหายในไฟล์ที่ได้เปิดส่วน Captions แล้วเลือกฝังลงภาพหรือส่งเป็นไฟล์แยก ถ้าเลือก None จะไม่มีซับ
  • ภาพดำหรือภาพค้างตอนท้ายมีคลิปหรือกราฟิกเกินจุดจบของเรื่อง ลบออกหรือตั้ง Range ให้ตรง
  • ไฟล์ใหญ่เกินส่งไม่ได้ลด bitrate ด้วย preset Medium หรือ Low อย่าลดขนาดภาพจนเล็กกว่าที่ปลายทางต้องการ

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

  • ตัวเลือก Content Credentials ตอน export เพิ่มเข้ามาในเวอร์ชัน 26.2
