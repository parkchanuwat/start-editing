Sequence คืออะไร และควรตั้งค่าแบบไหน

Sequence คือไทม์ไลน์ของงานหนึ่งชิ้น เก็บลำดับคลิป เสียง เอฟเฟกต์ และกำหนดขนาดภาพกับเฟรมเรตของงาน ตั้งให้ตรงกับปลายทางตั้งแต่ต้น ภาพจะไม่ยืด ไม่กระตุก และ export ง่าย

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ไม่แน่ใจว่าจะตั้งค่าอะไร? ลากคลิปหลักไปวางบนไอคอน New Item ที่มุมล่างของ Project panel Premiere จะสร้าง sequence ที่ขนาดภาพและเฟรมเรตตรงกับคลิปนั้นให้ทันที

Sequence คืออะไร

  • โปรเจกต์หนึ่งมีได้หลาย sequence เช่น ตัวเต็มแนวนอนสำหรับ YouTube กับตัวสั้นแนวตั้งสำหรับ Reels ใช้ฟุตเทจชุดเดียวกัน
  • Sequence เก็บสองอย่าง คือ สิ่งที่ตัดต่อ (คลิปบน track วิดีโอและเสียง เอฟเฟกต์ กราฟิก) กับ settings (ขนาดภาพ เฟรมเรต รูปแบบเสียง)
  • Editing Mode ใน settings ไม่ได้กำหนดไฟล์สุดท้าย ไฟล์ที่ได้จริงเลือกตอน export

สร้าง sequence 3 วิธี

  1. สร้างจากคลิป (ง่ายที่สุด)

    ลากคลิปจาก Project panel ไปวางบนไอคอน New Item หรือคลิกขวาที่คลิปแล้วเลือก New Sequence From Clip ได้ sequence ที่ตรงกับคลิปทันที

    เหมาะเมื่อปลายทางเหมือนกับที่กล้องถ่ายมา เช่น ถ่าย 1920×1080 25p และจะลง YouTube แนวนอน

  2. สร้างจากเมนู แล้วตั้งเอง

    ไปที่ File › New › Sequence (Ctrl+N / Cmd+N) เลือก preset ที่ใกล้เคียง หรือไปแท็บ Settings เลือก Editing Mode เป็น Custom แล้วกรอกค่าเอง

    ตั้งเสร็จแล้วกด Save Preset ตั้งชื่อเช่น "Reels 1080x1920 25p" ครั้งหน้าเลือกได้เลย

  3. ลากคลิปแรกลง sequence ว่าง

    ถ้า settings ของคลิปไม่ตรงกับ sequence Premiere จะถามว่าจะเปลี่ยน sequence ให้ตรงกับคลิป หรือคง settings เดิมไว้ ถ้าตั้ง sequence ตามปลายทางไว้แล้ว (เช่น แนวตั้ง) ให้เลือกคงค่าเดิม

เปลี่ยน settings ทีหลัง

ไปที่ Sequence › Sequence Settings หรือคลิกขวาที่ sequence ใน Project panel แล้วเลือก Sequence Settings ถ้าเปลี่ยน Frame Size ให้ติ๊ก Scale motion effects proportionally when changing frame size เพื่อให้ตำแหน่งและขนาดของคลิปปรับตามสัดส่วน

อย่าลด Frame Size เพื่อแก้เครื่องเล่นกระตุก ให้ลดความละเอียดตอนเล่น (playback resolution) ที่ Program Monitor แทน

จุดที่มือใหม่พลาดบ่อย

  • ใส่คลิป 4K ใน sequence 1080 แล้วภาพซูมเข้าคลิกขวาที่คลิปใน timeline เลือก Set to Frame Size ภาพจะพอดีเฟรมและยังซูมกลับได้คมเพราะไฟล์ต้นฉบับใหญ่กว่า
  • เฟรมเรตของ sequence ไม่ตรงกับกล้องภาพจะกระตุกหรือเฟรมซ้ำ ใช้วิธีสร้าง sequence จากคลิปหลักจะไม่พลาดเรื่องนี้
  • ตัดคลิปแนวตั้งใน sequence แนวนอนจะมีขอบดำสองข้าง ทำ sequence แนวตั้งแยกไว้ต่างหาก
  • ตั้ง Fields หรือ Pixel Aspect Ratio ผิดภาพมีเส้นหวีหรือยืด เลือก No Fields และ Square Pixels สำหรับฟุตเทจทั่วไป

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

Premiere 25.x–26.x
  • ขั้นตอนในหน้านี้ใช้ได้เกือบทั้งหมด ชื่อเมนูหลักไม่เปลี่ยน
  • ตัวเลือกด้านการจัดการสี เช่น Auto Tone Map Media อาจไม่มี หรืออยู่คนละที่ในเวอร์ชันเก่า
  • Mac ที่ใช้ชิป Intel ใช้ได้ถึงเวอร์ชัน 26.x เพราะ Premiere 27.0 เลิกรองรับแล้ว
