แต่งสีคลิปด้วย Color Mode

แก้ภาพมืด ภาพจาง หรือภาพอมสี ให้ดูเป็นธรรมชาติ ด้วยหน้าแต่งสีใหม่ของ Premiere: เปิด Color Mode เลือกคลิป แล้วปรับทีละค่าตามลำดับ

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ดูคลิปสอนที่ใช้ Lumetri Color panel อยู่? Premiere 27.0 เลิกใช้พาเนลนี้แล้ว แต่ Lumetri Color effect ยังมีอยู่ และโปรเจกต์เก่าที่แต่งด้วย Lumetri ยังเปิดได้ตามเดิม งานใหม่ให้ใช้ Color Mode ตามหน้านี้

ก่อนเริ่ม

  • ใช้ Premiere 27.0 ขึ้นไป เช็กเวอร์ชันได้ที่ About Premiere (Windows อยู่ในเมนู Help, Mac อยู่ในเมนู Premiere)
  • ตัดต่อ sequence ให้เสร็จก่อน จะได้ไม่เสียเวลาแต่งสีคลิปที่ถูกตัดทิ้งทีหลัง
  • ตั้ง Color Management ของ sequence ให้ถูกตั้งแต่แรก ค่าเริ่มต้นคือ Direct Rec. 709 (SDR) ถ้าทำคลิปลงโซเชียลหรือ YouTube แบบทั่วไป ใช้ค่านี้ได้เลย งาน HDR ค่อยเลือก Rec. 2100 HLG หรือ PQ ถ้าไปเปลี่ยนหลังแต่งสีแล้ว สีของคลิปจะเปลี่ยนตาม

ขั้นตอน

  1. เปิด Color Mode

    ใน Edit mode เปิด sequence ที่จะแต่งสีใน Timeline แล้วคลิกแท็บ Color บนแถบด้านบนสุดของหน้าต่าง Premiere จะเปิด workspace สำหรับแต่งสีให้ทันที

    ใน Color Mode ยังเปิด Project Browser ได้ อยากสลับไปแต่ง sequence อื่นก็ไม่ต้องกลับไป Edit mode

  2. เลือกคลิปใน Clip Grid

    Clip Grid แสดงทุกคลิปใน sequence เป็นภาพย่อ เรียงตามลำดับใน timeline คลิกภาพย่อของคลิปที่จะแก้ คลิปที่มีกรอบสีขาวคือ Current Clip ทุกค่าที่ปรับจะลงที่คลิปนี้

  3. เช็กว่ากำลังแก้คลิปเดียว

    ด้านบนของพาเนล Color Controls มีให้เลือก operation

    • Clip Operation แก้เฉพาะคลิปที่เลือก ถูกเลือกไว้ให้เองทุกครั้งที่คลิกคลิปใหม่
    • Sequence Style ใส่ลุคให้ทั้ง sequence มือใหม่ค่อยใช้ตอนท้าย หลังแก้รายคลิปเสร็จ

  4. ลองกด Auto Color ก่อน

    ปุ่ม Auto Color อยู่มุมล่างซ้ายของคอนโทรล Adjust จะปรับ Exposure, Temperature และ Tint ให้อัตโนมัติ ถ้าอยากให้แก้อย่างเดียว คลิกขวาหรือคลิกค้างที่ปุ่ม แล้วเลือก Auto Exposure หรือ Auto White Balance

    Auto Color คำนวณจากเฟรมที่ playhead อยู่ ให้วาง playhead บนเฟรมที่เป็นตัวแทนของคลิปก่อนกด

  5. ปรับเองด้วยการคลิกแล้วลาก

    คอนโทรลส่วนใหญ่ปรับได้สองค่าพร้อมกัน ลากขึ้นลงคือค่าหลัก ลากซ้ายขวาคือค่ารอง

    1. คลิกในคอนโทรล 1 ครั้งเพื่อ ล็อก (latch) จะมี HUD ขึ้นมาแสดงกราฟของค่านั้น
    2. ลากเมาส์ หรือกดปุ่มลูกศรเพื่อปรับทีละนิด
    3. คลิกอีกครั้ง หรือกด Enter / Esc เพื่อยืนยันและปลดล็อก

    ถ้าไม่อยากล็อก ให้กดเมาส์ค้าง ลาก แล้วปล่อยก็ได้ ปรับตามลำดับที่ Adobe แนะนำ

  6. เทียบภาพ แล้วไปคลิปถัดไป

    เลือกหลายคลิปใน Clip Grid แล้วเปิด Comparison View ใน Color Monitor จะเห็นภาพแบ่งครึ่งเทียบกัน เสร็จแล้วกด ↓ ไปคลิปถัดไป หรือ ↑ ย้อนกลับ ทำจนครบทุกคลิปที่ต้องแก้

คอนโทรลพื้นฐานใน Adjust

เริ่มจากคอนโทรลกลุ่ม Color & Contrast ซึ่งปรับทั้งภาพ ห้าตัวนี้แก้ปัญหาส่วนใหญ่ของมือใหม่ได้

คอนโทรลค่าหลัก (ลากขึ้นลง)ค่ารอง (ลากซ้ายขวา)ใช้แก้
Contrastความต่างระหว่างส่วนสว่างสุดกับมืดสุดเลื่อนจุด pivot ของคอนทราสต์ได้ภาพแบน ไม่มีมิติ
Exposureความสว่างโดยรวมBlack: กดส่วนมืดให้ดำขึ้น หรือยกให้จางลงภาพมืดหรือสว่างเกิน ภาพจาง
Temperatureอุ่นขึ้นหรือเย็นลงTint: ลดอาการอมเขียวหรืออมม่วงแดงภาพอมส้ม อมฟ้า อมเขียว
Balanceผสมช่องสีแดง เขียว น้ำเงินใหม่ ดันสีไปทิศไหนก็ได้ใช้แทน Temperature เมื่อสีเพี้ยนไปทางอื่นที่ไม่ใช่ส้มหรือฟ้า
Saturationเพิ่มหรือลดความสดของทุกสีพร้อมกันสีซีดหรือจัดเกิน

ลำดับที่ Adobe แนะนำสำหรับมือใหม่

  1. Contrast และ Exposure ปรับ Black ตามต้องการ
  2. Temperature หรือ Balance เลือกอย่างใดอย่างหนึ่ง
  3. Saturation ทั้งภาพ
  4. Zones ถ้ายังมีบางช่วงแสงต้องแก้ เริ่มต้นมีให้ 2 โซนคือ Shadows กับ Highlights
  5. Saturation/Hue/Lum Shift แก้เฉพาะสีใดสีหนึ่ง เช่น สีท้องฟ้า
  6. Texture และ Sharpness ปรับความคมของรายละเอียด
  7. Style ถ้าต้องการลุคเฉพาะตัว

คีย์ลัดที่ใช้บ่อย

Color Mode มีชุดคีย์ลัดแยกจาก Edit mode ปุ่มเดียวกันอาจทำงานต่างกันในสองโหมด

ปุ่มทำอะไรใช้ตอนไหน
H กดค้างซ่อน HUD ชั่วคราว ปล่อยแล้วกลับมาระหว่างปรับ อยากเห็นภาพเต็ม
← ↑ → ↓ปรับทีละนิดขณะคอนโทรลถูกล็อกอยู่

จุดที่มือใหม่พลาดบ่อย

  • หา Lumetri Color panel ไม่เจอPremiere 27.0 เลิกใช้แล้ว ใช้ Color Mode แทน ถ้าแค่อยากแก้นิดหน่อยโดยไม่ออกจาก Edit mode ใช้ส่วน Color ใน Properties panel
  • แต่งเสร็จแล้วค่อยไปเปลี่ยน Color Managementสีทุกคลิปจะเปลี่ยนตาม ตั้งให้ถูกก่อนเริ่มแต่ง
  • ตั้งใจแก้คลิปเดียว แต่ทุกคลิปเปลี่ยนเพราะกำลังอยู่ที่ Sequence Style ดูชื่อ operation ด้านบน Color Controls ก่อนลาก
  • ใส่ Lumetri Color effect ซ้อนกับ Color ModeAdobe แนะนำให้โปรเจกต์ใหม่ใช้ Color Mode อย่างเดียว เพราะใช้ร่วมกันจะจำกัดการแต่งสี และ Lumetri อาจตัดค่าที่เกินช่วงทิ้ง (clip) ซึ่งกู้คืนทีหลังไม่ได้
  • ดัน Zones หรือ Hue Shift หนักเกินภาพจะดูปลอม ใช้เท่าที่จำเป็น และดูกราฟใน HUD ว่าค่าชนขอบบนหรือล่างหรือยัง

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

Premiere 26.x และสาย LTS 25.6.x
  • เวอร์ชันเหล่านี้ยังมี Lumetri Color panel และไม่มี Color Mode ตัวจริง ขั้นตอนในหน้านี้จึงใช้ไม่ได้ ให้ดูหน้า "แต่งสีด้วย Lumetri Color" แทน
  • Color Mode เคยเปิดให้ลองเป็น public beta ในแอป Premiere (beta) ตั้งแต่ เม.ย. 2569 หน้าจอในรุ่น beta อาจต่างจาก 27.0
  • อัปเดตเป็น 27.0 แล้ว โปรเจกต์ที่แต่งด้วย Lumetri ยังเปิดได้ ค่าที่ทำไว้ยังอยู่ และปรับต่อได้ใน Effect Controls
