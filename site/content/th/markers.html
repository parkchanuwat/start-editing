Marker: ปักหมุดบน timeline

Marker คือหมุดที่ปักไว้บนเวลา ใช้จดโน้ตว่าต้องแก้อะไร แบ่งตอนของวิดีโอ หรือมาร์กจังหวะเพลงไว้ตัดตาม กด M ครั้งเดียวก็ปักได้

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

เปิด Markers panel ไว้ด้วย ที่ Window › Markers จะเห็น marker ทั้งหมดเป็นรายการ ดับเบิลคลิกเพื่อดูรายละเอียด และรุ่นล่าสุดยังแสดงตำแหน่งจุด In/Out ปนอยู่ในรายการด้วย

ประเภทของ marker

ประเภทใช้ทำอะไรตัวอย่าง
Commentจดโน้ตตรงจุดนั้นของ timeline"ตัดเสียงไอออก" "ลูกค้าขอเปลี่ยนเพลงตรงนี้"
Chapterจุดแบ่งตอนให้คนดูกระโดดไปได้ในวิดีโอที่เสร็จแล้วเปิดเรื่อง วิธีทำ สรุป

Web Linkแนบ URL ที่ให้ข้อมูลเพิ่มเติมของช่วงนั้นลิงก์สินค้าที่พูดถึง

Clip marker กับ Sequence marker

Clip marker ปักใน Source Monitor จะติดไปกับคลิปนั้น เอาคลิปไปวางที่ไหนก็เห็น marker ตามไปด้วย เหมาะกับการมาร์กช่วงดีในฟุตเทจ

Sequence marker ปักใน Program Monitor หรือบน timeline จะอยู่บนเวลาของ sequence เหมาะกับโน้ตงานตัดต่อและ chapter

ขั้นตอน

  1. วาง playhead แล้วกด M

    ย้าย playhead ไปจุดที่ต้องการ กด M หรือคลิกปุ่ม Add Marker ใต้จอ จะได้ marker บนแถบเวลา

    กด M ระหว่างเล่นเพลงได้เลย ปักตามจังหวะกลองแล้วค่อยตัดคลิปให้ตรงหมุด คลิปจะ snap เข้าหา marker เอง

  2. ดับเบิลคลิก marker เพื่อแก้รายละเอียด

    ตั้งชื่อ ใส่คอมเมนต์ เปลี่ยนสี เลือกประเภท และใส่ Duration ถ้าอยากให้ marker เป็นช่วงเวลาแทนจุดเดียว

  3. กระโดดไปมาระหว่าง marker

    กด Shift+M ไป marker ถัดไป และ Ctrl+Shift+M / Cmd+Shift+M ย้อนกลับ หรือคลิกในรายการของ Markers panel

  4. จัดการหลาย marker พร้อมกัน

    ใน Markers panel เลือก track item ตั้งแต่สองอันขึ้นไปจะเห็น marker ของทุกอันรวมกัน และลบหลาย marker ที่เลือกได้ในครั้งเดียว

เอา marker ไปใช้ทำอะไรได้บ้าง

  • รับคอมเมนต์จากลูกค้า ปัก Comment ตามจุดที่ต้องแก้ แล้วไล่ทีละหมุดด้วย Shift+M
  • ตัดตามจังหวะเพลง ปักตามบีตก่อน แล้วลากคลิปให้ snap กับหมุด
  • ทำ chapter ให้ YouTube ใช้เวลาของ Chapter marker ไปเขียนเป็นรายการเวลาในคำอธิบายวิดีโอ (ทำตามกติกา chapter ของ YouTube) เดโมด้านบนแสดงตัวอย่างข้อความ
  • แบ่งช่วงโฆษณา ใช้ Segmentation marker ทำเป็นช่วงเวลา ให้คนรับไฟล์รู้ว่าตรงไหนแทรกโฆษณาได้

คีย์ลัด

ปุ่มทำอะไร
Mเพิ่ม marker ตรง playhead
Shift+Mไป marker ถัดไป
Ctrl+Shift+M / Cmd+Shift+Mไป marker ก่อนหน้า
ดับเบิลคลิก markerเปิดหน้าต่างแก้ชื่อ คอมเมนต์ สี และประเภท

จุดที่มือใหม่พลาดบ่อย

  • ปัก marker แล้วหาไม่เจอใน timelineเพราะไปปักใน Source Monitor มันเลยกลายเป็น clip marker อยู่บนคลิป ไม่ใช่บนแถบเวลาของ sequence
  • ลบช่วงใน timeline แล้ว marker ไม่ขยับตามsequence marker อยู่กับเวลา ไม่ได้อยู่กับคลิป เมื่อ ripple delete ให้เปิดตัวเลือก Ripple Sequence Markers ในเมนู Markers ถ้าต้องการให้ขยับตาม
  • ใช้สีมั่วจนทีมงงตกลงความหมายของสีในทีมก่อน เช่น แดงคือต้องแก้ เขียวคือผ่าน และตั้งสีเริ่มต้นของ marker ได้ในการตั้งค่า
  • คิดว่า Chapter marker จะไปขึ้นเป็น chapter ใน YouTube เองYouTube ทำ chapter จากรายการเวลาในคำอธิบายวิดีโอ ต้องคัดลอกไปใส่เอง
