เริ่มที่นี่

ทำคลิปแรกตั้งแต่ต้นจนจบ

หน้านี้พาทำวิดีโอสั้นหนึ่งชิ้นใน Premiere ตั้งแต่เตรียมไฟล์จนได้ไฟล์ MP4 ทำตามลำดับทีละขั้น แต่ละขั้นมีลิงก์ไปหน้าที่อธิบายละเอียด ทำจบหนึ่งรอบแล้วจะเห็นภาพรวมของทั้งโปรแกรม

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ใช้ Premiere ภาษาเกาหลีหรือจีนตัวย่ออยู่? เว็บนี้ใช้ชื่อเมนูภาษาอังกฤษ ถ้าจะเปลี่ยนภาษาของโปรแกรม ไปที่ Creative Cloud desktop › Preferences แล้วเลือก Default install language (อยู่ในหัวข้อ Apps หรือ Language แล้วแต่เวอร์ชัน) จากนั้นถอนการติดตั้ง Premiere แล้วติดตั้งใหม่ ภาษาจึงจะเปลี่ยน

ก่อนเริ่ม

  • ฟุตเทจ 3–10 คลิปจากมือถือหรือกล้อง และเพลงหนึ่งเพลงที่มีสิทธิ์ใช้
  • พื้นที่ว่างในดิสก์พอสมควร Premiere จะสร้างไฟล์ cache และ preview เพิ่มระหว่างทำงาน
  • ตัดสินใจก่อนว่าจะลงที่ไหน แนวนอนสำหรับ YouTube หรือแนวตั้งสำหรับ Shorts / Reels เพราะกำหนดขนาด sequence

8 ขั้นตอน

  1. เตรียมโฟลเดอร์และ import

    สร้างโฟลเดอร์งาน เช่น MyVlog ข้างในมี Footage และ Music สร้างโปรเจกต์ใหม่ไว้ในโฟลเดอร์นี้ แล้วลากไฟล์เข้า Project panel ห้ามย้ายหรือเปลี่ยนชื่อไฟล์หลัง import

    จัดการไฟล์และโปรเจกต์ →

  2. สร้าง sequence

    ลากคลิปหลักไปที่ไอคอน New Item ถ้าจะทำแนวตั้ง สร้าง sequence 1080×1920 เอง

    Sequence และ Sequence Settings →

  3. คัดฟุตเทจ

    ดับเบิลคลิกคลิปเพื่อเปิดใน Source Monitor กด I และ O เลือกช่วงที่ดีที่สุด แล้วกด , เพื่อ Insert ลง timeline ทำทีละคลิปตามลำดับเรื่อง

    Source Monitor กับ Program Monitor →

  4. ตัดต่อบน timeline

    วางเพลงลง track เสียง ปักหมุดจังหวะด้วย M ตัดคลิปให้ลงจังหวะด้วย Razor แล้วปิดช่องว่างด้วย Ripple Delete เล่นดูทั้งเรื่องบ่อย ๆ

    ตัดต่อบน Timeline → · Marker →

  5. ใส่ title และกราฟิก

    เปิด Window › Graphics Templates ลาก template ชื่อเรื่องไปไว้ track V2 แล้วแก้ข้อความใน Properties panel

    MOGRT → · Effects และ Keyframe →

  6. แต่งสี

    คลิกแท็บ Color กด Auto Color ทีละคลิป แล้วปรับ Contrast, Exposure และ Temperature ให้ทุกคลิปดูไปทางเดียวกัน

    แต่งสีด้วย Color Mode →

  7. ใส่ซับ

    ถ้ามีเสียงพูด ใช้ Speech to Text ถอดเสียง สร้าง captions แล้วตรวจคำผิดและความยาวบรรทัด

    ซับไตเติลภาษาเกาหลีและจีนตัวย่อ →

  8. Export

    คลิกแท็บ Export เลือก Format H.264 และ Preset Match Source – Adaptive High Bitrate เช็กขนาดภาพกับ frame rate แล้วกด Export

    Preset และ Resolution →

นิสัยที่ช่วยให้งานไม่พัง

  • กด Ctrl+S / Cmd+S บ่อย ๆ และเปิด Auto Save ไว้เสมอ
  • ตัดเรื่องให้เสร็จก่อนแต่ง แต่งสี ใส่เอฟเฟกต์ และทำซับหลังจากลำดับคลิปนิ่งแล้ว จะไม่ต้องทำซ้ำ
  • ดูบนจอปลายทาง งานแนวตั้งให้ส่งไฟล์เข้ามือถือดูก่อนโพสต์จริง
  • workspace หน้าตาเพี้ยน ไปที่ Window › Workspaces › Reset to Saved Layout พาเนลจะกลับที่เดิม

จุดที่มือใหม่พลาดบ่อย

  • import จากโฟลเดอร์ Downloads หรือเดสก์ท็อปแล้วลบทิ้งทีหลังคลิปจะขึ้น Media Offline ย้ายไฟล์เข้าโฟลเดอร์งานก่อน import
  • ตั้ง sequence ผิดแนวรู้ตัวตอนจะ export ว่าต้องการแนวตั้ง ตั้งให้ถูกตั้งแต่ขั้นที่ 2
  • แต่งสีหรือทำซับก่อนตัดเสร็จตัดคลิปเพิ่มทีหลังต้องทำซ้ำหลายรอบ
  • ใช้เพลงที่ไม่มีสิทธิ์วิดีโออาจโดนปิดเสียงหรือติด claim บนแพลตฟอร์ม เลือกเพลงที่ใช้ได้ตั้งแต่แรก
