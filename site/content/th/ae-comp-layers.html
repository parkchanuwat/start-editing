Composition และ Layer

ใน After Effects งานหนึ่งชิ้นเรียกว่า composition มีขนาดภาพ frame rate และความยาวของตัวเอง ข้างในประกอบด้วย layer ที่ซ้อนกันเหมือนแผ่นใส layer ที่อยู่บนจะบังของที่อยู่ข้างล่าง

  • After Effects 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ต่างจาก Premiere ตรงนี้: track ใน Premiere วางได้หลายคลิปต่อกัน แต่ layer ใน After Effects มีต้นฉบับได้แค่ชิ้นเดียว งานหนึ่งจึงมักมี layer หลายสิบชั้น

สร้าง composition

  1. สร้างจากฟุตเทจ (ง่ายสุด)

    ลากไฟล์วิดีโอจาก Project panel ไปวางบนไอคอน New Composition ด้านล่างของพาเนล composition จะได้ขนาดและ frame rate ตามไฟล์นั้น

  2. หรือสร้างเอง

    เลือก Composition › New Composition (Ctrl+N / Cmd+N) เลือก Preset หรือพิมพ์ Width, Height, Frame Rate และ Duration เอง

  3. แก้ค่าทีหลังได้

    เลือก Composition › Composition Settings (Ctrl+K / Cmd+K) เปลี่ยนความยาวหรือขนาดได้ตลอด

ชนิดของ layer

Layerคืออะไรสร้างจาก
Footageวิดีโอ ภาพนิ่ง หรือเสียงที่ import มาลากจาก Project panel
Textตัวหนังสือที่แก้และ animate ได้Layer › New › Text
Shapeรูปทรงเวกเตอร์ คมทุกขนาดShape tools หรือ Pen tool
Solidพื้นสีเรียบ ใช้เป็นพื้นหลังหรือที่ใส่เอฟเฟกต์Ctrl+Y / Cmd+Y
Adjustmentใส่เอฟเฟกต์แล้วมีผลกับทุก layer ข้างล่างLayer › New › Adjustment Layer
Null Objectlayer ที่มองไม่เห็น ใช้คุมการเคลื่อนไหวของ layer อื่นLayer › New › Null Object
Precompcomposition ที่ถูกวางเป็น layer ในอีก compositionCtrl+Shift+C / Cmd+Shift+C

Transform: ห้าค่าที่ทุก layer มี

กดตัวอักษรเพื่อเปิดดูค่านั้นของ layer ที่เลือก: A Anchor Point · P Position · S Scale · R Rotation · T Opacity กด Shift ค้างแล้วกดตัวอื่นเพื่อเปิดหลายค่าพร้อมกัน

ดูผลงาน

  • กด Spacebar เพื่อ preview แถบสีเขียวบน timeline คือช่วงที่ cache ไว้แล้ว จะเล่นลื่น
  • ลด Resolution ของ Composition panel เลือก Half หรือ Quarter ตอนทำงานเพื่อให้ preview เร็วขึ้น ค่านี้ไม่ได้เปลี่ยนขนาดของ composition
  • ตั้ง work area กด B และ N เพื่อตั้งจุดเริ่มและจุดจบของช่วงที่จะ preview

ข้อผิดพลาดที่มือใหม่เจอบ่อย

  • ใส่ของแล้วมองไม่เห็นlayer อาจอยู่ล่าง layer พื้นทึบ ลาก layer ขึ้นไปข้างบนใน Timeline
  • งงระหว่าง Resolution กับขนาด compositionResolution ใน Composition panel คือคุณภาพตอน preview ส่วนขนาดจริงอยู่ใน Composition Settings
  • composition สั้นกว่าที่ต้องการเปลี่ยน Duration ใน Composition Settings ไม่ใช่ลากปลาย layer
  • แก้ผิด compositionดูชื่อแท็บด้านบนของ Timeline ก่อนแก้ทุกครั้ง โดยเฉพาะเมื่อมี precomp หลายชั้น
