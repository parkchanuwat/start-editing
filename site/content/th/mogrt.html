MOGRT (Motion Graphics Template)

ไฟล์ .mogrt คือกราฟิกเคลื่อนไหวสำเร็จรูปที่แก้ได้ เช่น แถบชื่อคนพูด ไตเติลเปิดเรื่อง หรือโลโก้เคลื่อนไหว คนออกแบบทำไว้ครั้งเดียว คนตัดต่อแค่เปลี่ยนข้อความ สี หรือรูป งานทั้งเรื่องจึงหน้าตาไปในทางเดียวกัน

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ดูคลิปสอนเก่าแล้วหาเมนูไม่เจอ? คลิปเก่ามักใช้แท็บ Browse และ Edit ใน Essential Graphics panel ปัจจุบันหา template ที่พาเนล Graphics Templates และแก้ค่าใน Properties panel

ทำไมต้องใช้ MOGRT

  • ใช้ซ้ำได้ทั้งเรื่อง แถบชื่อ 20 คนหน้าตาเหมือนกันหมด แก้แค่ชื่อ
  • แก้ได้เฉพาะที่คนออกแบบเปิดไว้ เช่น ข้อความ สี ตัวเลือกแอนิเมชัน ส่วนที่เหลือถูกล็อก งานจึงไม่หลุดแบรนด์
  • ทำของยาก ๆ จาก After Effects ได้ template ที่ทำใน After Effects ใส่ particle เอฟเฟกต์พิเศษ หรือ 3D ได้ คนตัดต่อใช้ใน Premiere โดยไม่ต้องเปิด After Effects เอง
  • มีแบบพิเศษ เช่น template ที่ดึงข้อมูลจากไฟล์ CSV/TSV มาทำกราฟ และ template ที่เปลี่ยนรูปหรือวิดีโอข้างในได้ (Media Replacement)

ใช้ template ใน Premiere

  1. เปิด Graphics Templates panel

    ไปที่ Window › Graphics Templates แล้วเลือกแท็บ My Templates จะเห็น template ที่ติดตั้งไว้ รวมถึงชุดที่มากับโปรแกรม

  2. ลากลง timeline

    ลาก template ไปวางบน track วิดีโอที่อยู่เหนือฟุตเทจ เช่น V2

  3. แก้ค่าใน Properties panel

    เลือกคลิป template ใน timeline แล้วดูที่ Properties panel จะมีช่องให้แก้ตามที่คนออกแบบกำหนด เช่น ข้อความ สี ตัวเลือกแอนิเมชัน และบางตัวแก้ฟอนต์ ขนาด หรือ faux style ได้

  4. ปรับความยาว

    ลากขอบซ้ายหรือขวาของคลิป template ใน timeline เพื่อให้สั้นหรือยาวขึ้น

ติดตั้งไฟล์ .mogrt ที่ได้มา

  • กดปุ่ม Install Motion Graphics template ใน Graphics Templates panel แล้วเลือกไฟล์ .mogrt
  • หา template เพิ่มจาก Adobe Stock ได้จากในโปรแกรม
  • ใช้ร่วมกันในทีม: คลิกขวาที่ template เลือก Copy to Library เพื่อเก็บไว้ใน Creative Cloud Libraries

ทำ template เองใน After Effects (ภาพรวม)

  1. เปิด workspace สำหรับทำ template

    ใน After Effects ไปที่ Window › Workspace › Essential Graphics แล้วเลือก composition หลักใส่ใน Essential Graphics panel

  2. ลาก property ที่จะให้แก้ได้

    ลาก property จาก timeline ไปวางใน Essential Graphics panel เช่น Source Text หรือสีของ shape ทุกอย่างที่ลากมาคือช่องที่คนตัดต่อจะเห็นใน Premiere

  3. จัดกลุ่มและตั้งชื่อให้เข้าใจง่าย

    ใช้เมนู Add Formatting › Add Group ที่มุมล่างซ้ายของพาเนล เพื่อรวมช่องที่เกี่ยวกันไว้ด้วยกัน

  4. Export

    กด Export Motion Graphics Template ไฟล์ภาพ วิดีโอ และ pre-comp ที่จำเป็นจะถูกแพ็กไปกับ template

กราฟิกที่สร้างใน Premiere เองก็ export เป็น .mogrt ได้เหมือนกัน เหมาะกับ title ง่าย ๆ ที่ใช้ซ้ำบ่อย

จุดที่มือใหม่พลาดบ่อย

  • ฟอนต์ใน template หาย ตัวหนังสือเพี้ยนเครื่องไม่มีฟอนต์ที่คนออกแบบใช้ ติดตั้งหรือเปิดใช้ฟอนต์นั้นก่อน โดยเฉพาะฟอนต์ไทยที่ไม่ได้มากับระบบ
  • หาช่องแก้ไม่เจอtemplate แก้ได้เฉพาะช่องที่คนออกแบบเปิดไว้ ถ้าต้องแก้มากกว่านั้นต้องกลับไปแก้ใน After Effects
  • template จาก After Effects เล่นกระตุกตัวที่ซับซ้อนประมวลผลหนัก ให้ render ช่วงนั้นก่อนดู
  • ยืดความยาวแล้วแอนิเมชันเข้าออกผิดจังหวะถ้าคนออกแบบตั้ง Responsive Design ไว้ แอนิเมชันช่วงเข้าและออกจะคงเดิมเมื่อยืด ถ้าไม่ได้ตั้ง ให้ใช้ความยาวใกล้กับค่าเดิม

ถ้าใช้เวอร์ชันเก่า

Premiere รุ่นเก่าที่ยังมี Essential Graphics panel
  • รุ่นเก่าใช้แท็บ Browse สำหรับหา template และแท็บ Edit สำหรับแก้ค่า ขั้นตอนเหมือนกัน ต่างแค่ที่อยู่ของเมนู
  • Legacy Titler ถูกยกเลิกไปแล้ว title เก่าควรอัปเกรดเป็น Source Graphics
