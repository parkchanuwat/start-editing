สเปกเครื่องและการติดตั้ง

ก่อนติดตั้ง Premiere หรือ After Effects 27.0 ให้เช็กสามอย่าง คือระบบปฏิบัติการ RAM และการ์ดจอ เวอร์ชัน 27.0 ตัดการรองรับ Windows รุ่นเก่าและ Mac ชิป Intel ออกแล้ว

  • Premiere และ After Effects 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

Windows 11 เวอร์ชัน 23H2 ติดตั้ง 27.0 ไม่ได้ ต้องอัปเดตเป็น 24H2 ขึ้นไปก่อน ส่วน Mac ต้องเป็นชิป Apple silicon (M1 ขึ้นไป) และ macOS 15 ขึ้นไป

ตัวเลขนี้สรุปจากหน้า Technical requirements ของ Adobe ณ วันที่อัปเดต รุ่น CPU ที่รองรับและรายละเอียดอื่นดูในหน้าต้นฉบับ

ขั้นตอนติดตั้ง

  1. เช็กเวอร์ชันระบบปฏิบัติการ

    Windows: Settings › System › About ดูที่ Version ต้องเป็น 24H2 ขึ้นไป · Mac: เมนู Apple › About This Mac ดูชิปและเวอร์ชัน macOS

  2. เช็ก VRAM ของการ์ดจอ (Windows)

    เปิด Task Manager › แท็บ Performance › เลือก GPU แล้วดู Dedicated GPU memory ถ้าต่ำกว่า 4 GB อาจเปิด Premiere ไม่ได้หรือใช้งานไม่ไหว

  3. ติดตั้ง Creative Cloud desktop app

    ดาวน์โหลดจากเว็บ Adobe แล้วล็อกอินด้วย Adobe ID ต้องต่ออินเทอร์เน็ตเพื่อ activate

  4. ตั้งภาษาก่อนกดติดตั้ง

    ใน Creative Cloud desktop app เปิด Preferences › Apps แล้วเลือก Default install language ทั้งสองโปรแกรมมีภาษา 한국어 และ 简体中文 ให้เลือก

    ภาษาจะใช้กับโปรแกรมที่ติดตั้งหลังจากนี้ ถ้าอยากเปลี่ยนภาษาของโปรแกรมที่ติดตั้งไปแล้ว ต้องถอนการติดตั้งแล้วติดตั้งใหม่

  5. ติดตั้ง Premiere และ After Effects เวอร์ชันเดียวกัน

    กด Install ทั้งสองตัวจากรายการ Apps ถ้าจะใช้ Dynamic Link ต้องเป็นเวอร์ชันเดียวกัน

ถ้ากำลังจะซื้อเครื่องใหม่

  • RAM 32 GB ถ้าตั้งใจทำ 4K หรือใช้ After Effects เป็นประจำ
  • การ์ดจอแยก VRAM 8 GB ขึ้นไป บน Windows เพื่อเอฟเฟกต์และฟีเจอร์ AI ที่ใช้ GPU
  • SSD สองลูก ลูกหนึ่งสำหรับระบบและโปรแกรม อีกลูกสำหรับไฟล์งานและ cache
  • Mac ต้องเป็น Apple silicon และเลือก unified memory ให้พอตั้งแต่ตอนซื้อ เพราะเพิ่มทีหลังไม่ได้

ข้อผิดพลาดที่มือใหม่เจอบ่อย

  • Windows 11 23H2 กดอัปเดตไม่ได้เวอร์ชัน 27.0 บล็อกการติดตั้งบน 23H2 อัปเดต Windows เป็น 24H2 ขึ้นไปก่อน
  • Mac ชิป Intel ไม่เห็น 27.027.0 รองรับเฉพาะ Apple silicon Mac ชิป Intel ใช้ได้ถึงเวอร์ชัน 26.x
  • ติดตั้งไปแล้วได้ภาษาที่ไม่ต้องการเปลี่ยน Default install language แล้วถอนติดตั้งและติดตั้งใหม่
  • เก็บฟุตเทจบน HDD ภายนอกช้า ๆเล่นกระตุกได้แม้เครื่องแรง ย้ายไฟล์งานไปไว้บน SSD

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

เวอร์ชัน 26.x และ 25.x
  • 26.x ต้องใช้ Windows 11 v24H2 เหมือนกัน และยังรองรับ Mac ชิป Intel
  • 25.x ยังรองรับ Windows 10 v22H2
  • Adobe แจ้งว่าตั้งแต่ 28.0 จะบล็อกการติดตั้งบนระบบที่ใช้พื้นฐาน Windows 10 ทั้งหมด รวมถึง Windows Server 2022
