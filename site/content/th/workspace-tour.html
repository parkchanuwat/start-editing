รู้จักหน้าจอและพาเนล

หน้าจอ Premiere แบ่งเป็นพาเนลหลายช่อง แต่ละช่องมีหน้าที่ของตัวเอง ด้านบนสุดคือ header bar สำหรับสลับโหมดทำงาน ถ้าพาเนลหายหรือเลย์เอาต์เละ กดรีเซ็ตกลับได้เสมอ

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

เลย์เอาต์เละ? ไปที่ Window › Workspaces › Reset to Saved Layout หรือดับเบิลคลิกชื่อ workspace บน header bar พาเนลจะกลับไปอยู่ที่เดิม

Header bar และโหมดทำงาน

ตอนเปิดโปรแกรมจะเจอหน้า Home ก่อน เมื่อกด New Project โปรแกรมจะเปิดในโหมด Import พอสร้างหรือเปิด project แล้วจะเข้าโหมด Edit และเมื่อพร้อมส่งออกให้ไปที่โหมด Export เวอร์ชัน 27.0 มีโหมด Color สำหรับแต่งสีเพิ่มเข้ามาด้วย

ด้านขวาของ header bar มีชื่อ project, เมนู Workspaces, ปุ่ม Quick Export และปุ่มขยายวิดีโอเต็มจอ

พาเนลที่ใช้บ่อย

พาเนลมีไว้ทำอะไรคีย์ลัด
Projectเก็บไฟล์ที่ import และ sequence จัดเป็น bin ได้Shift+1
Source Monitorดูคลิปดิบและตั้งจุด In/OutShift+2
Timelineที่ตัดต่อจริง เรียงคลิปบน trackShift+3
Program Monitorแสดงผลของ sequenceShift+4
Effect Controlsค่าของเอฟเฟกต์และ keyframe ของคลิปที่เลือกShift+5
Effectsรายการเอฟเฟกต์และทรานซิชันทั้งหมดShift+7
Propertiesปรับค่าที่ใช้บ่อยของคลิปที่เลือกในที่เดียว เช่นขนาด ตำแหน่ง ความดังเสียงเมนู Window
Essential Soundตั้งประเภทเสียง ปรับความดัง duckingเมนู Window

กด ` (ปุ่มซ้ายของเลข 1) เพื่อขยายพาเนลที่เลือกเต็มหน้าจอ กดอีกครั้งเพื่อกลับ

จัดหน้าจอให้ใช้ง่าย

  1. เลือก workspace ให้ตรงงาน

    เปิดเมนู Workspaces ทางขวาบน มี workspace สำเร็จรูปหลายแบบ เช่น Editing, Audio และ Captions and Graphics ซึ่งจัดพาเนลไว้ให้เหมาะกับงานนั้น

  2. ลากพาเนลไปวางใหม่

    ลากแท็บชื่อพาเนลไปวางที่ขอบของพาเนลอื่น จะเห็นพื้นที่ไฮไลต์ว่าจะไปวางตรงไหน

  3. บันทึกเลย์เอาต์ของตัวเอง

    เมื่อจัดเสร็จ เลือก Window › Workspaces › Save as New Workspace แล้วตั้งชื่อ

  4. หาพาเนลที่หายไป

    ทุกพาเนลเปิดได้จากเมนู Window ถ้าปิดไปโดยไม่ตั้งใจ เปิดจากตรงนั้นได้เลย

หน้าจอ After Effects ต่างกันตรงไหน

After Effects มีพาเนลคล้ายกัน แต่ใช้ชื่อต่าง: Composition แทน Program Monitor, Timeline แสดง layer ซ้อนกันแทน track และมี Effects & Presets กับ Properties อยู่ด้านขวา ดูเพิ่มที่หน้า Composition และ Layer

ข้อผิดพลาดที่มือใหม่เจอบ่อย

  • เปิด project ของคนอื่นแล้วหน้าจอเปลี่ยนถ้าเปิด Import Workspace From Projects ไว้ Premiere จะใช้เลย์เอาต์ที่บันทึกมากับ project ปิดตัวเลือกนี้ในเมนู Window › Workspaces
  • Reset แล้วไม่กลับเป็นค่าเริ่มต้นReset to Saved Layout จะกลับไปที่เลย์เอาต์ที่บันทึกล่าสุดของ workspace นั้น ถ้าเคยบันทึกทับไว้ ให้เปลี่ยนไปใช้ workspace อื่นที่ยังไม่ได้แก้
  • พาเนลเล็กเกินจนอ่านไม่ออกใช้ ` ขยายชั่วคราว หรือลากเส้นแบ่งระหว่างพาเนล

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

Premiere 25.x–26.x
  • header bar มีเฉพาะ Import, Edit และ Export ยังไม่มีโหมด Color
  • การแต่งสีใช้ Lumetri Color panel ใน workspace Color
