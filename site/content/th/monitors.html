Source Monitor กับ Program Monitor ต่างกันยังไง

Source Monitor ใช้ดูและเลือกช่วงจากคลิปดิบทีละคลิป ส่วน Program Monitor แสดงผลงานที่กำลังตัดอยู่ใน sequence จำง่าย ๆ ว่าจอซ้ายคือวัตถุดิบ จอขวาคือสิ่งที่คนดูจะเห็น

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

มีอะไรเปลี่ยนใน 27.0: Clip Match และโหมดเทียบภาพ (Comparison Mode) ใน monitor ของ Edit mode ถูกถอดออกแล้ว การเทียบภาพเพื่อแต่งสีย้ายไปอยู่ใน Color Mode

ขั้นตอน: คัดคลิปจาก Source ไปลง timeline

  1. เปิดคลิปใน Source Monitor

    ดับเบิลคลิกคลิปใน Project panel คลิปจะขึ้นที่ Source Monitor โดยยังไม่ไปอยู่ใน sequence

  2. เลือกช่วงที่จะใช้

    เล่นหาจุดเริ่ม กด I เพื่อตั้ง In แล้วหาจุดจบ กด O เพื่อตั้ง Out ช่วงระหว่างสองจุดคือส่วนที่จะถูกวาง

  3. เลือกว่าจะเอาภาพ เสียง หรือทั้งคู่

    ลากไอคอน Drag video หรือ Drag audio ใต้จอ ไปวางใน timeline ถ้าต้องการแค่อย่างเดียว

  4. วาง playhead ใน timeline

    ย้าย playhead ไปจุดที่จะวางคลิป และเช็กว่า track ที่จะรับคลิปถูกเปิด target ไว้

  5. กด Insert หรือ Overwrite

    • Insert , แทรกคลิปตรง playhead คลิปที่อยู่หลังจากนั้นถูกดันไปทางขวา sequence ยาวขึ้น
    • Overwrite . วางทับของเดิมเท่าความยาวคลิป sequence ไม่ยาวขึ้นถ้าวางในช่วงที่มีคลิปอยู่แล้ว

  6. ดูผลและเอาช่วงที่ไม่ใช้ออกใน Program Monitor

    ตั้ง In/Out ใน Program Monitor แล้วกด Lift ; เพื่อยกออกโดยเหลือช่องว่าง หรือ Extract ' เพื่อเอาออกแล้วปิดช่องว่างให้

จุดที่มือใหม่พลาดบ่อย

  • กด Overwrite แล้วคลิปเดิมหายไปOverwrite วางทับจริง ๆ กด Ctrl+Z / Cmd+Z แล้วใช้ Insert แทนถ้าต้องการแทรก
  • Insert แล้วเสียงหลุด syncถ้าบาง track ถูกปิด Sync Lock ไว้ track นั้นจะไม่ถูกดันตาม เปิด Sync Lock ให้ทุก track ที่ต้องเลื่อนไปด้วยกัน
  • คลิปไปลง track ที่ไม่ได้ตั้งใจดูปุ่ม source patching และ track targeting ทางซ้ายของ timeline ว่าเปิดไว้ที่ track ไหน
  • ภาพใน Program Monitor แตก เลยคิดว่าไฟล์เสียอาจเป็นเพราะตั้ง Resolution ของจอไว้ที่ 1/2 หรือ 1/4 เพื่อให้เล่นลื่น ไฟล์ที่ export ไม่เป็นไปด้วย
  • ใส่ marker ผิดที่marker ที่ปักใน Source Monitor จะติดไปกับคลิป ถ้าอยากได้หมุดบน timeline ให้ปักใน Program Monitor หรือ timeline

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

Premiere 26.x และเก่ากว่า
  • Program Monitor ยังมีโหมด Comparison และ Clip Match สำหรับเทียบสีระหว่างคลิป ซึ่ง 27.0 ย้ายไปไว้ใน Color Mode
  • ปุ่มและคีย์ลัด Insert, Overwrite, Lift, Extract ใช้เหมือนเดิม
