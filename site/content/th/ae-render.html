After Effects

Render และส่งออก

After Effects ส่งงานออกเป็นไฟล์ผ่าน Render Queue ถ้าต้องการ MP4 ใช้ H.264 ได้ในตัว ถ้าต้องการพื้นหลังโปร่งใสหรือหลายไฟล์พร้อมกัน ก็มีทางเลือกของมัน

  • After Effects 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ค่าเริ่มต้นคือ H.264 ถ้าติดตั้งใหม่หรือล้างค่า Output Module ไว้ After Effects จะใช้ preset H.264 – Match Render Settings – 15 Mbps เป็นค่าเริ่มต้น

ขั้นตอน render เป็น MP4

  1. เพิ่ม composition เข้าคิว

    เลือก composition แล้วไปที่ File › Export › Add to Render Queue (Ctrl+M / Cmd+M) Render Queue panel จะเปิดขึ้น

  2. เช็ก Render Settings

    ปกติใช้ Best Settings ดูช่อง Time Span ด้วยว่าจะ render ทั้ง composition หรือแค่ work area

  3. เลือก Output Module

    คลิกชื่อ Output Module แล้วเลือก Format เป็น H.264 จะมี preset 5, 15 และ 40 Mbps ให้เลือกตามความละเอียดและคุณภาพที่ต้องการ

  4. ตั้งชื่อและที่เก็บไฟล์

    คลิกชื่อไฟล์ที่ช่อง Output To แล้วเลือกโฟลเดอร์

  5. กด Render

    กดปุ่ม Render ด้านขวาของ Render Queue panel รอจนแถบเสร็จ แล้วเปิดดูไฟล์ที่ได้

เลือก format ตามการใช้งาน

ต้องการFormatChannels
ไฟล์สำหรับเว็บหรือโซเชียลH.264RGB
วิดีโอพื้นหลังใสไปวางทับใน PremiereQuickTime, codec Apple ProRes 4444RGB + Alpha
ภาพนิ่งเรียงเฟรมPNG SequenceRGB หรือ RGB + Alpha
ไฟล์ master คุณภาพสูงQuickTime, codec Apple ProRes 422 HQRGB

ตั้งค่าเริ่มต้นของ Output Module เองได้ที่ Edit › Templates › Output Module

ส่งให้ Media Encoder หรือ Premiere

  • Adobe Media Encoder เลือก File › Export › Add to Adobe Media Encoder Queue เหมาะเมื่อต้องการหลายไฟล์หลายสเปก และอยากทำงานใน After Effects ต่อระหว่าง render
  • Dynamic Link ไป Premiere import composition เข้า Premiere ได้เลยโดยไม่ต้อง render แก้ใน After Effects แล้ว Premiere อัปเดตตาม ต้องใช้เวอร์ชันเดียวกัน

ข้อผิดพลาดที่มือใหม่เจอบ่อย

  • ได้ไฟล์สั้นกว่าที่คิดTime Span ใน Render Settings ตั้งเป็น work area อยู่ เปลี่ยนเป็นความยาวทั้ง composition หรือขยาย work area
  • MP4 พื้นหลังเป็นสีดำH.264 เก็บความโปร่งใสไม่ได้ ใช้ QuickTime ProRes 4444 และตั้ง Channels เป็น RGB + Alpha
  • ไม่รู้ว่าไฟล์ไปอยู่ไหนดูช่อง Output To ก่อนกด Render ทุกครั้ง
  • render ช้ามากปิด layer ที่ไม่ใช้ และเช็กว่าเปิด Multi-Frame Rendering ไว้ใน Preferences

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

After Effects 25.x–26.x
  • Render Queue และ H.264 ในตัวใช้แบบเดียวกัน
  • 27.0 เพิ่มแถบปรับระดับการบีบอัดของ PNG (ยังไม่สูญเสียคุณภาพ) และปรับปรุง Auto-Save ให้กู้งานได้ง่ายขึ้น
