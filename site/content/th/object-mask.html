Object Mask: เลือกคนหรือวัตถุด้วยคลิกเดียว

Object Mask ใช้ AI หาคนหรือวัตถุในภาพให้อัตโนมัติ คลิกครั้งเดียวได้ mask แล้วสั่งให้ mask วิ่งตามวัตถุตลอดช็อต จากนั้นใส่เอฟเฟกต์เฉพาะในหรือนอก mask ได้ ไม่ต้องไปทำ rotoscope ใน After Effects

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

ใช้ครั้งแรกต้องรอแป๊บหนึ่ง Premiere จะดาวน์โหลดโมเดล AI ก่อน ระหว่างนั้นยังใช้ Object Mask ไม่ได้ ดูความคืบหน้าได้ที่ Progress panel

เอาไปใช้ทำอะไรได้

  • เบลอหน้าคน ทะเบียนรถ หรือโลโก้ ที่ไม่ได้รับอนุญาตให้เผยแพร่ ช่วยเรื่องความเป็นส่วนตัวของคนในภาพ
  • เบลอหรือทำพื้นหลังเป็นขาวดำ ให้คนในภาพเด่นขึ้น โดยใช้ Inverted
  • ปรับแสงหรือสีเฉพาะคน เช่น หน้ามืดเพราะย้อนแสง ทำให้สว่างขึ้นโดยฉากหลังไม่เปลี่ยน
  • วางตัวหนังสือไว้หลังคน ทำสำเนาคลิปไว้ track บน เปลี่ยน mask เป็น Opacity Mask แล้ววางตัวหนังสือไว้ระหว่างสอง track

ขั้นตอน: เบลอพื้นหลังให้คนเด่น

  1. เลือก Object Mask Tool

    ในแถบเครื่องมือ (toolbar) กดค้างที่กลุ่มเครื่องมือ mask จะเห็น Object Mask อยู่รวมกับ Ellipse, Rectangle และ Pen

  2. ชี้แล้วคลิกที่วัตถุ

    เลือกคลิปใน timeline แล้วชี้เมาส์ใน Program Monitor วัตถุที่ตรวจเจอจะมีไฮไลต์ขึ้น คลิกเพื่อเลือก

    เริ่มจากเฟรมที่เห็นวัตถุชัดที่สุด mask จะออกมาแม่นกว่า

  3. ถ้าไม่ไฮไลต์ ให้วาดคร่าว ๆ

    สลับเป็นโหมด Rectangle หรือ Lasso จากเมนูด้านล่างของ Program Monitor แล้ววาดล้อมวัตถุ ใช้ปุ่ม + และ − เพิ่มหรือลบส่วน กด Alt / Option ค้างเพื่อสลับชั่วคราว

  4. Track ให้ mask วิ่งตาม

    ใน Effect Controls จะเห็น mask ใหม่อยู่ในส่วน Unassigned Masks ใช้ปุ่ม track ไปข้างหน้าและย้อนหลังเพื่อให้ mask ตามวัตถุทั้งคลิป เลือกคุณภาพได้สองแบบคือ Faster และ Better

  5. ใส่เอฟเฟกต์

    เปิด Effects panel ลาก Gaussian Blur ไปใส่คลิป mask จะไปผูกกับเอฟเฟกต์นั้นเอง เอฟเฟกต์จึงมีผลแค่ในพื้นที่ mask

  6. กลับด้านและเกลี่ยขอบ

    ติ๊ก Inverted เพื่อให้เบลอเฉพาะนอก mask คือพื้นหลัง แล้วปรับ Feather ให้ขอบนุ่ม และ Expansion ขยายหรือหด mask

  7. ยกเลิกการเลือก mask ก่อนดูผล

    ระหว่างที่ mask ยังถูกเลือก จะมีสีแดงทับในจอ คลิกที่อื่นใน Effect Controls ก่อนเล่นดูผลจริง

ตั้งค่าที่ควรรู้

ค่าทำอะไรใช้เมื่อ
Sharp / SmoothSharp ให้ขอบคมชัด Smooth ให้ขอบนุ่มผม ขนสัตว์ ผ้าบาง หรือของกึ่งโปร่งใส ใช้ Smooth
Sharpnessปรับว่าขอบนุ่มของโหมด Smooth จะกินเข้ามาแค่ไหน เลือกปรับแบบ S-Curve หรือ Levelsดึงเส้นผมที่หลุดกลับมา หรือตัดขอบพื้นหลังที่ติดมา
Featherทำขอบ mask ให้นุ่มให้เอฟเฟกต์กลืนกับภาพ
Expansionค่าลบหด mask ค่าบวกขยายmask เล็กหรือใหญ่กว่าวัตถุเล็กน้อย
Opacityความเข้มของ maskลดความแรงของเอฟเฟกต์
Invertedสลับให้เอฟเฟกต์มีผลนอก maskเบลอหรือแต่งพื้นหลัง

ไฟล์ mask เก็บที่ไหน

ข้อมูล mask ถูกเก็บในโฟลเดอร์ชื่อ <ชื่อโปรเจกต์> Masks ข้างไฟล์โปรเจกต์ ย้ายโปรเจกต์ไปเครื่องอื่นต้องย้ายโฟลเดอร์นี้ไปด้วย ถ้าหาไม่เจอ Object Mask จะขึ้นว่า offline ใน Effect Controls ให้กด Locate ชี้ไปที่โฟลเดอร์ mask อื่น ๆ ที่ไม่ใช่ Object Mask ไม่ได้รับผลกระทบ

Premiere ลบไฟล์ mask ที่ไม่ได้ใช้แล้วให้เองเมื่อปิดโปรเจกต์ ช่วยประหยัดพื้นที่ดิสก์

จุดที่มือใหม่พลาดบ่อย

  • ส่งโปรเจกต์ให้คนอื่นแล้ว mask หายลืมส่งโฟลเดอร์ Masks ไปด้วย
  • เห็นภาพเป็นสีแดง เลยคิดว่าเอฟเฟกต์ผิดคือ overlay ตอนที่ mask ถูกเลือกอยู่ ยกเลิกการเลือกก่อนดู
  • mask ไม่ตามวัตถุยังไม่ได้กด track หรือเริ่ม track จากเฟรมที่วัตถุถูกบัง ลองเริ่มจากเฟรมที่เห็นชัดแล้ว track ทั้งสองทาง
  • mask ไปค้างอยู่ใน Unassigned Masksยังไม่ได้ใส่เอฟเฟกต์ให้ mask ลากเอฟเฟกต์ลงคลิป หรือใส่เอฟเฟกต์ไว้ก่อนแล้วค่อยสร้าง mask
  • ขอบผมดูแข็งเป็นก้อนเปลี่ยนเป็นโหมด Smooth แล้วปรับ Sharpness

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

ประวัติเวอร์ชันของ Object Mask
  • Object Mask มาครั้งแรกใน Premiere 26.0 (ม.ค. 2569) เวอร์ชัน 25.x ไม่มีเครื่องมือนี้ ต้องวาด mask ด้วยมือแล้ว track เอง
  • โหมด Smooth ออกมาทีหลังในช่วงต้นปี 2569 และ 26.5 ตรวจจับวัตถุได้มากขึ้น ขอบแม่นขึ้น
  • Mac ชิป Intel และ Windows ที่ใช้ไดรเวอร์การ์ดจอ AMD รุ่นเก่า จะใช้โมเดลรุ่นก่อนหน้า และ Premiere 27.0 เลิกรองรับ Mac ชิป Intel แล้ว
