จัดการไฟล์และโปรเจกต์ ไม่ให้เจอ Media Offline

ไฟล์โปรเจกต์ของ Premiere (.prproj) ไม่ได้เก็บวิดีโอไว้ในตัว มันจำแค่ว่าไฟล์อยู่ที่ไหนและชื่ออะไร ถ้าย้ายหรือเปลี่ยนชื่อไฟล์ คลิปจะกลายเป็นจอแดง Media Offline รู้หลักนี้ข้อเดียวก็กันปัญหาไปได้เกือบหมด

  • Premiere 27.0
  • อัปเดต 27 พ.ย. 2569
  • ระดับมือใหม่
  • อ้างอิง Adobe Help Center

กฎข้อเดียวที่ควรจำ: เก็บฟุตเทจไว้ในโฟลเดอร์เดียวกับไฟล์โปรเจกต์ หรือโฟลเดอร์ย่อยของมัน และอย่าเปลี่ยนชื่อไฟล์หรือโฟลเดอร์หลัง import

  • หนึ่งงานหนึ่งโฟลเดอร์ ทุกอย่างที่ใช้ในงานอยู่ข้างใน ย้ายไปไหนก็ย้ายทั้งโฟลเดอร์
  • ถ้าใช้ไดรฟ์ภายนอก ให้เสียบไว้ตลอดตอนทำงาน
  • ทำงานในทีมบน Windows ที่เก็บไฟล์บนเครือข่าย ให้ map เป็นตัวอักษรไดรฟ์ และใช้ตัวอักษรเดียวกันทุกเครื่อง

Premiere ตามหาไฟล์ที่ย้ายยังไง

  1. ดูที่อยู่เดิมก่อน

    Premiere จำที่อยู่ของแต่ละไฟล์ไว้สูงสุด 3 ตำแหน่งในโปรเจกต์ปกติ (ที่อยู่ปัจจุบันกับของเก่าอีกสองแห่ง) ถ้าย้ายกลับไปที่เดิมก็เจอเอง

  2. ค้นอัตโนมัติ 2 รอบ

    รอบแรกค้นในโฟลเดอร์ที่มีไฟล์โปรเจกต์และโฟลเดอร์ย่อยทั้งหมด รอบสองขึ้นไปหนึ่งระดับแล้วค้นทั้งโฟลเดอร์แม่ รวมถึงโฟลเดอร์ข้าง ๆ

  3. ถ้ายังไม่เจอ หน้าต่าง Link Media จะเปิดขึ้น

    ให้ชี้ไปที่ไฟล์เอง หรือคลิกขวาที่คลิป offline ใน Project panel แล้วเลือก Link Media เมื่อไรก็ได้

    ไฟล์ที่ถูกแปลงนามสกุล เช่น ทำ proxy หรือ transcode มา ให้เอาติ๊ก File Extension ใต้ Match File Properties ออกก่อนค้น

ที่ต้อง relink เองเสมอคือ ไฟล์หรือโฟลเดอร์ถูกเปลี่ยนชื่อ โครงสร้างโฟลเดอร์ถูกรื้อใหม่ หรือไดรฟ์ไม่ได้เสียบ

ย้ายหรือส่งโปรเจกต์ไปเครื่องอื่น

  1. ใช้ Project Manager

    ไปที่ File › Project Manager เลือก sequence ที่จะเอาไป แล้วเลือก Collect Files and Copy to New Location Premiere จะก๊อปเฉพาะไฟล์ที่ใช้จริงไปไว้ที่ใหม่พร้อมไฟล์โปรเจกต์

  2. อย่าลืมโฟลเดอร์ Masks

    ถ้าใช้ Object Mask ให้ส่งโฟลเดอร์ <ชื่อโปรเจกต์> Masks ที่อยู่ข้างไฟล์โปรเจกต์ไปด้วย

  3. ฟอนต์และ template

    เครื่องปลายทางต้องมีฟอนต์ที่ใช้ใน title และ MOGRT ด้วย ไม่อย่างนั้นตัวหนังสือจะเปลี่ยนเป็นฟอนต์อื่น

Auto Save และการกู้งาน

ตั้งที่ Edit › Preferences › Auto Save (Mac: Premiere › Settings › Auto Save) เลือกให้บันทึกอัตโนมัติทุกกี่นาที และเก็บไว้กี่เวอร์ชัน ไฟล์สำรองจะอยู่ในโฟลเดอร์ Auto-Save ข้างไฟล์โปรเจกต์ ถ้าโปรแกรมปิดเองหรือไฟล์โปรเจกต์เสีย ให้เปิดไฟล์ล่าสุดในโฟลเดอร์นี้

Media cache คืออะไร ลบได้ไหม

ตอน import Premiere สร้างไฟล์ช่วยเล่น เช่น ไฟล์เสียงที่แปลงแล้วและไฟล์ index เก็บไว้ใน media cache ซึ่งใช้ร่วมกับ Media Encoder และ After Effects ไฟล์พวกนี้ลบได้ เมื่อต้องใช้โปรแกรมจะสร้างใหม่

  • ตั้งค่าที่ Edit › Preferences › Media Cache (Mac: Premiere › Settings › Media Cache) ย้ายที่เก็บไปไดรฟ์ที่เร็วและพื้นที่เหลือเยอะได้
  • ตั้งให้ลบไฟล์เก่าอัตโนมัติเมื่อ cache ใหญ่เกินกำหนด ดิสก์จะไม่เต็มโดยไม่รู้ตัว
  • ถ้าเสียงหรือภาพเล่นเพี้ยนแปลก ๆ การล้าง cache แล้วเปิดโปรเจกต์ใหม่มักช่วยได้

จุดที่มือใหม่พลาดบ่อย

  • import จากการ์ดหน่วยความจำโดยตรงถอดการ์ดเมื่อไรคลิป offline ทันที ก๊อปไฟล์ลงเครื่องก่อน
  • จัดโฟลเดอร์ใหม่ระหว่างทำงานไฟล์ที่ย้ายออกนอกโฟลเดอร์โปรเจกต์จะหาไม่เจอ จัดให้เสร็จก่อนเริ่ม
  • ลบฟุตเทจที่คิดว่าไม่ได้ใช้ใช้ Project Manager แยกไฟล์ที่ใช้จริงออกมาก่อนค่อยลบ
  • ไดรฟ์เต็มเพราะ cacheตั้งขนาด cache สูงสุดและให้ลบไฟล์เก่าอัตโนมัติ

ถ้าใช้เวอร์ชันเก่ากว่า 27.0

Premiere 25.x–26.x

  • งานแบบ Team Projects จำที่อยู่เก่าของไฟล์ได้ไม่จำกัด ต่างจากโปรเจกต์ปกติที่จำได้ 3 ตำแหน่ง
