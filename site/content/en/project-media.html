Managing files and projects without Media Offline

A Premiere project file (.prproj) doesn't contain your video. It only remembers where each file lives and what it is called. Move or rename a file and the clip turns into a red Media Offline frame. Understanding that one fact prevents most problems.

  • Premiere 27.0
  • Updated 27 Nov 2026
  • Beginner
  • Based on Adobe Help Center

The one rule to remember: keep your media in the same folder as the project file, or in a subfolder of it, and don't rename files or folders after importing.

A folder structure that works

MyVlog/
  MyVlog.prproj
  Footage/
  Audio/
  Graphics/
  Exports/
  • One job, one folder. Everything the job uses lives inside it, and you always move the whole folder.
  • If you use an external drive, keep it connected while you work.
  • For teams on Windows with network storage, map a drive letter and use the same letter on every computer.

How Premiere finds moved files

  1. It checks old locations first

    A standard project remembers up to three locations per file (the current path plus two earlier ones). Move a file back and Premiere finds it.

  2. It searches automatically, twice

    The first pass searches the folder containing the project file and all its subfolders. The second goes up one level and searches the whole parent folder, including neighbouring folders.

  3. If it still can't find them, Link Media opens

    Point it at the files yourself, or right-click an offline clip in the Project panel and choose Link Media at any time.

    For files whose extension changed, such as proxies or transcodes, untick File Extension under Match File Properties before searching.

You always have to relink by hand when files or folders were renamed, the folder structure was reorganised, or a drive isn't connected.

Moving or handing over a project

  1. Use Project Manager

    Choose File › Project Manager, pick the sequences to take, and choose Collect Files and Copy to New Location. Premiere copies only the files actually used, together with the project file.

  2. Don't forget the Masks folder

    If you used Object Mask, send the <Project Name> Masks folder that sits next to the project file as well.

  3. Fonts and templates

    The other computer needs the fonts used in titles and MOGRTs, or the text switches to a different font.

Auto Save and recovering work

Set it under Edit › Preferences › Auto Save (Mac: Premiere › Settings › Auto Save): how often to save and how many versions to keep. Backups go in an Auto-Save folder next to the project file. If Premiere quits unexpectedly or the project file is damaged, open the latest file in that folder.

What the media cache is, and whether you can delete it

When you import, Premiere creates helper files such as conformed audio and index files and keeps them in the media cache, which it shares with Media Encoder and After Effects. They can be deleted; the apps rebuild them when needed.

  • Settings are in Edit › Preferences › Media Cache (Mac: Premiere › Settings › Media Cache). You can move the cache to a fast drive with plenty of space.
  • Have old cache files deleted automatically when the cache grows past a set size, so the disk doesn't fill up unnoticed.
  • If sound or picture plays back strangely, clearing the cache and reopening the project often helps.

Common beginner mistakes

  • Importing straight from a memory cardThe clips go offline the moment you remove the card. Copy the files to the computer first.
  • Reorganising folders mid-projectFiles moved outside the project folder can't be found. Finish organising before you start.
  • Deleting footage you think you don't needUse Project Manager to separate what is used first, then delete.
  • The drive fills up with cacheSet a maximum cache size and turn on automatic deletion of old files.

Using a version older than 27.0

Premiere 25.x–26.x
  • Link Media, Project Manager, Auto Save and Media Cache are in the same places.
  • Team Projects remember unlimited earlier file locations, unlike standard projects, which remember three.
