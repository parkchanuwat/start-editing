After Effects

Rendering and export

After Effects turns compositions into files through the Render Queue. For an MP4, H.264 is built in. For transparent video or many files at once, there are routes for those too.

  • After Effects 27.0
  • Updated 27 Nov 2026
  • Beginner
  • Based on Adobe Help Center

H.264 is the default. On a fresh install, or after clearing Output Module preferences, After Effects uses H.264 – Match Render Settings – 15 Mbps as the default output module.

Rendering an MP4

  1. Add the comp to the queue

    Select the composition and choose File › Export › Add to Render Queue (Ctrl+M / Cmd+M). The Render Queue panel opens.

  2. Check Render Settings

    Best Settings is the usual choice. Also check Time Span: the whole composition, or only the work area?

  3. Choose an Output Module

    Click the Output Module name and set Format to H.264. There are 5, 15 and 40 Mbps presets depending on resolution and the quality you want.

  4. Name the file and pick a folder

    Click the file name next to Output To and choose where it goes.

  5. Click Render

    Click Render on the right of the Render Queue panel, wait for the bar to finish, then open the file.

Pick a format for the job

You needFormatChannels
A file for the web or socialH.264RGB
Transparent video to overlay in PremiereQuickTime, Apple ProRes 4444 codecRGB + Alpha
An image sequencePNG SequenceRGB or RGB + Alpha
A high-quality masterQuickTime, Apple ProRes 422 HQ codecRGB

Set your own default output modules under Edit › Templates › Output Module.

Hand off to Media Encoder or Premiere

  • Adobe Media Encoder: choose File › Export › Add to Adobe Media Encoder Queue. Good for several files and specs, and you can keep working in After Effects while it renders.
  • Dynamic Link to Premiere: import the composition into Premiere without rendering. Changes in After Effects update in Premiere. Versions must match.

Common beginner mistakes

  • The file is shorter than expectedTime Span in Render Settings is set to the work area. Change it to the composition length or widen the work area.
  • MP4 has a black backgroundH.264 can't store transparency. Use QuickTime ProRes 4444 with Channels set to RGB + Alpha.
  • Can't find the fileCheck Output To every time before you click Render.
  • Rendering is very slowTurn off layers you don't need and make sure Multi-Frame Rendering is on in Preferences.

Using a version older than 27.0

After Effects 25.x–26.x
  • The Render Queue and built-in H.264 work the same way.
  • 27.0 adds a PNG compression slider (still lossless) and better Auto-Save recovery.
