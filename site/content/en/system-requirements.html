System requirements and install

Before installing Premiere or After Effects 27.0, check three things: your operating system, RAM and graphics card. Version 27.0 drops older Windows versions and Intel Macs.

  • Premiere & After Effects 27.0
  • Updated 27 Nov 2026
  • Beginner
  • Based on Adobe Help Center

Windows 11 version 23H2 can't install 27.0. Update to 24H2 or later first. On Mac you need Apple silicon (M1 or newer) and macOS 15 or later.

Installing

  1. Check your OS version

    Windows: Settings › System › About and look at Version; it must be 24H2 or later. Mac: Apple menu › About This Mac to see the chip and macOS version.

  2. Check your GPU memory (Windows)

    Open Task Manager › Performance › GPU and read Dedicated GPU memory. Below 4 GB, Premiere may not open or may be unusable.

  3. Install the Creative Cloud desktop app

    Download it from Adobe and sign in with your Adobe ID. You need an internet connection to activate.

  4. Set the language before installing

    In the Creative Cloud desktop app, open Preferences › Apps and choose a Default install language. Both apps offer 한국어 and 简体中文.

    The setting applies to apps you install afterwards. To change the language of an app that's already installed, uninstall and reinstall it.

  5. Install Premiere and After Effects at the same version

    Click Install for both in the Apps list. Dynamic Link needs matching versions.

If you're buying a computer

  • 32 GB RAM if you plan to work in 4K or use After Effects regularly.
  • A dedicated GPU with 8 GB+ VRAM on Windows, for GPU effects and AI features.
  • Two SSDs: one for the system and apps, one for media and cache.
  • Apple silicon on Mac, with enough unified memory from the start, because you can't add more later.

Common beginner mistakes

  • Can't update on Windows 11 23H227.0 blocks installation on 23H2. Update Windows to 24H2 or later.
  • 27.0 doesn't appear on an Intel Mac27.0 supports only Apple silicon. Intel Macs stay on 26.x.
  • The app installed in the wrong languageChange Default install language, then uninstall and reinstall.
  • Footage on a slow external hard drivePlayback can stutter even on a fast computer. Move media to an SSD.

Using a version older than 27.0

Versions 26.x and 25.x
  • 26.x also needs Windows 11 v24H2, and still supports Intel Macs.
  • 25.x still supports Windows 10 v22H2.
  • Adobe says that from 28.0, installation will be blocked on all Windows 10-based systems, including Windows Server 2022.
