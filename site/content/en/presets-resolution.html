Common presets and resolutions

Resolution is the image size in pixels, frame rate is how many images play per second, and a preset is a saved set of values you can pick when creating a sequence or exporting. This page lists the values that suit everyday work, with the reasons behind them.

  • Premiere 27.0
  • Updated 27 Nov 2026
  • Beginner
  • Based on Adobe Help Center and YouTube Help

A rule that works for most jobs: set up the sequence for its destination, then export with a Match Source preset, which takes its values from the sequence automatically. Change only what you need to.

YouTube recommends exporting at the frame rate you recorded. Avoid converting 25 to 30 or the reverse unless you must, because it causes stutter.

Exporting with a preset

  1. Open Export

    Select the sequence and click the Export tab in the header bar at the top of the window.

  2. Choose Format and Preset

    H.264 works almost everywhere. For the preset, choose Match Source – Adaptive High Bitrate, which uses the sequence's frame size and frame rate.

  3. Check the key values

    Confirm Frame Size and Frame Rate are what you expect. Leave Export Color Space at its Rec. 709 default for ordinary SDR work.

  4. Adjust the bitrate if needed

    VBR 1 pass is quick; VBR 2 pass takes longer but is usually higher quality. Hardware Accelerated encoding is the default and speeds up exports.

  5. Save your own preset

    Once your usual settings are in place, save them as a preset such as "Reels 1080x1920 25p" and pick it next time.

Common beginner mistakes

  • Exporting larger than the sequence to make it sharperA 1080p sequence exported as 4K isn't sharper, only bigger. When you must scale, turn on Use Maximum Render Quality to reduce jagged edges.
  • Bitrate too lowBusy, fast-moving scenes break into blocks. Start from YouTube's table.
  • Frame rate doesn't match the sequenceStutter. Match Source avoids this.
  • Delivering a vertical video as a landscape fileBlack bars on both sides. Set up a vertical sequence from the start.
  • 4K editing is sluggishEdit with proxies, then export from the original files.

Using an older version

Tutorials that still show the Export Settings window
  • Since version 22.0 (late 2021), exporting happens in the Export tab at the top. Older tutorials use the former Export Settings window; preset names and values are similar.
