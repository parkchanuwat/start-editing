Exporting video

Exporting turns a sequence into a video file that plays anywhere. In Premiere, start by asking where the file is going, then pick the preset that suits that destination.

  • Premiere 27.0
  • Updated 27 Nov 2026
  • Beginner
  • Based on Adobe Help Center

Always check Range. If In/Out points are left on the sequence, Premiere may export only that part. Set Range to Entire Source when you want everything.

Three ways to export

WayGood forWhere
Export modeEveryday jobs, full controlThe Export tab in the header bar, or Ctrl+M / Cmd+M
Quick ExportA fast file with a ready-made presetButton at the top right of the header bar
Send to Media EncoderSeveral files or specs, or editing while it exportsButton at the bottom right of Export mode

Steps in Export mode

  1. Select the sequence and open Export mode

    Click in the timeline or select the sequence in the Project panel, then click the Export tab.

  2. Choose a destination

    On the left, Media File makes an ordinary file, and some social destinations can upload for you.

  3. Set the file name, location and preset

    Give the file a name and location you'll find again, then choose a Preset such as Match Source – Adaptive High Bitrate, which uses H.264 at the sequence's frame size and frame rate.

  4. Check Range and Captions

    Range, under the preview, offers Entire Source, Source In/Out, Work Area and Custom. If you have captions, choose in Captions whether to leave them out, export a sidecar file or burn them into the picture.

  5. Check the estimated size and export

    Estimated File Size is at the bottom right. If it's too big to send, try a Medium Bitrate preset. Click Export and wait for it to finish.

  6. Watch the file you made

    Open the actual file and watch it through: picture, sound, captions, and no extra black at the end.

Settings worth knowing

SettingMeaning
FormatThe file type and codec, such as H.264 (MP4), HEVC or QuickTime (ProRes)
Match SourceAutomatically uses the source's frame size and frame rate
BitrateData per second; higher is sharper but bigger. VBR adapts to how complex the picture is; CBR stays constant.
Use Maximum Render QualityHelps quality when scaling down, but takes longer
Content CredentialsOptionally embeds who created and edited the file

For frame sizes and presets per destination, see Common presets and resolutions.

Common beginner mistakes

  • Only part of the video exportedRange was set to Source In/Out by leftover In/Out points. Switch to Entire Source.
  • Can't find the fileCheck Location before you click Export, and put a date or version in the file name.
  • Captions missing from the fileOpen Captions and choose to burn them in or export a sidecar file. With None there are no captions.
  • Black or frozen frames at the endA clip or graphic runs past the end of the edit. Remove it or set Range precisely.
  • File too big to sendLower the bitrate with a Medium or Low preset rather than shrinking the frame below what the destination needs.

Using a version older than 27.0

Premiere 25.x–26.x
  • Export mode and Quick Export work the same way.
  • The Content Credentials option at export arrived in 26.2.
