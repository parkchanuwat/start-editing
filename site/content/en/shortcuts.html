Keyboard shortcuts

You don't need to learn them all. Start with the dozen or so single keys you'll use every day and add more over time. Many letters exist in both apps but do different things; try them in the demo.

See and change shortcuts in the app

  1. Premiere

    Windows: Edit › Keyboard Shortcuts · Mac: Premiere › Keyboard Shortcuts. A keyboard map highlights keys that have commands, and you can search commands by name.

  2. After Effects

    Choose Edit › Keyboard Shortcuts to search and reassign keys the same way.

  3. Save your own set

    If you change shortcuts, save them as a new set rather than overwriting the default, so it's easy to go back.

Common beginner mistakes

  • The shortcut types a letter insteadA text field still has focus. Click in the timeline first, then press the key again.
  • A correct shortcut does nothingMany shortcuts only work when their panel is active. Look for the blue outline to see which panel has focus.
  • Shortcuts from a tutorial don't matchThe video may use an older version or a customised set. Check the Keyboard Shortcuts window on your own machine.
