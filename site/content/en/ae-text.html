Animating text

Text in After Effects can move as a whole layer, or character by character, word by word or line by line using text animators. The fastest way in is to apply an animation preset and then look at how it's built.

  • After Effects 27.0
  • Updated 27 Nov 2026
  • Beginner
  • Based on Adobe Help Center

Reverse-engineer a preset: apply an animation preset to a text layer, then press U or UU to see only the properties it animates or changes.

Create a text layer

  1. Choose the Type tool

    Press Ctrl+T / Cmd+T. Click once in the Composition panel for single-line point text, or drag a box for paragraph text.

  2. Set font and size

    Use the Character panel or the Properties panel. For Korean or Chinese, choose a font that contains those characters, or you'll see empty boxes.

Method 1: an animation preset

  1. Open the Effects & Presets panel

    Go to Animation Presets › Text for categories such as Animate In, Animate Out and Blurs.

  2. Drag a preset onto the text layer

    It starts at the playhead. Press Spacebar to see it.

    To preview presets before applying them, choose Browse Presets from the Effects & Presets panel menu to open them in Adobe Bridge.

Method 2: build it with a text animator

  1. Add an animator

    Expand the text layer in the Timeline, click Animate and choose a property such as Opacity or Position, or use Animation › Animate Text.

  2. Set the characters' "target" value

    For example, set Opacity to 0%. Characters inside the Range Selector get this value.

  3. Animate the Range Selector

    Expand Range Selector 1, turn on the stopwatch for Start at 0%, move forward in time and set Start to 100%. The characters appear one by one.

  4. Choose the unit under Advanced

    In Range Selector › Advanced › Based On, choose whether it counts characters, words or lines.

Ideas to try

  • Typewriter: Opacity 0%, then animate Start from 0 to 100%.
  • Rise in letter by letter: Position Y +30 and Opacity 0% in the same animator.
  • Jitter: add a Wiggly Selector instead of a Range Selector.
  • Changing weight: use a variable font and add an animator for its Weight axis.

Common beginner mistakes

  • Animating the whole layer instead of each characterA layer's Transform moves the whole block. For per-character motion you need an animator.
  • Mixing up Start and EndCharacters between Start and End are the ones that get the animator's values. Watch the range bars in the Composition panel.
  • Korean or Chinese shows as boxesThe font lacks those characters. Switch to a font that supports the language.
  • Text motion looks choppyTurn on motion blur for the text layer.

Using a version older than 27.0

After Effects 25.x–26.x
  • Text animators and the Range Selector work the same way.
  • Animating variable font axes arrived in 26.0.
  • Editable text from Illustrator files arrived in 27.0.
