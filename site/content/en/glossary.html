Pairs beginners often mix up

PairThe difference
Sequence / CompositionThe unit of work in Premiere / in After Effects
Render / ExportRendering processes frames for smooth playback or output; exporting makes the final file (After Effects uses "render" for both)
Codec / ContainerHow it's compressed, such as H.264 / the file wrapper, such as .mp4
Frame size / Resolution in After EffectsThe comp's real size / preview quality in the Composition panel
Ripple / Rolling editChange length and push later clips / move the cut between two clips, keeping total length
Insert / OverwritePlace and push existing material / place over it
Clip marker / Sequence markerTravels with the clip / stays on the sequence's time
