Tour of the workspace

Premiere's screen is split into panels, each with its own job. The header bar at the top switches between modes. If a panel disappears or the layout gets messy, you can always reset it.

  • Premiere 27.0
  • Updated 27 Nov 2026
  • Beginner
  • Based on Adobe Help Center

Layout in a mess? Choose Window › Workspaces › Reset to Saved Layout, or double-click the workspace name in the header bar, and the panels go back where they were.

The header bar and modes

Premiere opens on the Home screen. Choose New Project and it opens in Import mode. Once a project is created or opened you're in Edit mode, and when you're ready to deliver you go to Export mode. Version 27.0 adds a Color mode for grading.

On the right of the header bar are the project name, the Workspaces menu, the Quick Export button and the button that maximises video output.

Make the screen work for you

  1. Pick a workspace for the job

    Open the Workspaces menu at the top right. Ready-made layouts such as Editing, Audio and Captions and Graphics arrange panels for that kind of work.

  2. Drag panels to new places

    Drag a panel's tab to the edge of another panel; a highlighted area shows where it will land.

  3. Save your own layout

    When you're happy, choose Window › Workspaces › Save as New Workspace and give it a name.

  4. Find a missing panel

    Every panel can be opened from the Window menu, so if you close one by accident, reopen it there.

How After Effects differs

After Effects has similar panels with different names: the Composition panel instead of the Program Monitor, a Timeline of stacked layers instead of tracks, and Effects & Presets and Properties on the right. See Compositions and layers.

Common beginner mistakes

  • Opening someone's project changes your screenWith Import Workspace From Projects on, Premiere uses the layout saved in the project. Turn it off under Window › Workspaces.
  • Reset doesn't go back to the defaultReset to Saved Layout returns to the last saved version of that workspace. If you saved over it, switch to another workspace you haven't changed.
  • Panels too small to readPress ` to maximise temporarily, or drag the dividers between panels.

Using a version older than 27.0

Premiere 25.x–26.x
  • The header bar has only Import, Edit and Export; there's no Color mode.
  • Grading uses the Lumetri Color panel in the Color workspace.
